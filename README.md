# App del clima

Aplicación web para consultar las condiciones meteorológicas actuales de cualquier ciudad mediante el consumo de una API externa.

## Funcionalidades
- Búsqueda de clima por nombre de ciudad.
- Visualización de temperatura actual, humedad, velocidad del viento y estado del cielo.
- Manejo de errores cuando no se encuentra la ciudad ingresada o falla la conexión.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript (Fetch API / Async-Await)
- API de clima

## Ejecución local
1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en tu navegador web.
